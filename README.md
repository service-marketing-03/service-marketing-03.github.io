# Relief 촉각 태블릿 홍보 사이트

서비스 마케팅 3조 과제용 홍보·판매촉진 사이트입니다. 시각장애 대학생을 위한 촉각 태블릿과 콘텐츠 변환·관리 서비스를 소개합니다. 브랜드명, 제품 사양, 가격, 프로모션은 기획안 예시입니다.

- 사이트: https://service-marketing-03.github.io
- 접근성: 시맨틱 마크업, 본문 바로가기, 키보드 조작, 화면낭독기용 대체 텍스트, 큰 글씨·고대비 토글, 섹션별 음성으로 듣기, 점자·음성 홍보물 신청
